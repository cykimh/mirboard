# 게임판·대기실 다듬기 7건 (D-160~, 2026-10-30)

사용자 요청은 2026-10-30 에 일곱 건으로 왔다.

## 사용자 결정 (2026-10-30)

- 원카드! 버튼 크기는 **방장이 대기실에서** 정한다. 방 설정이라 모두 같은 크기다.
- 손패 최대 2줄은 **원카드만** 적용한다.
- 전원이 준비해도 **자동 시작하지 않는다**. 준비는 표시만 하고, 시작은 늘 방장이 한다.
- 랭킹 게임 순서는 **전체에서 많이 한 게임**부터다.
- 티츄 강퇴는 허용하되, 확인 창에 "팀전이라 판이 끝나요"를 알린다.

### A — 세부

1. **차례 효과**
   - 차례 좌석은 테두리를 두껍게 하고 빛이 천천히 맥박친다. 위에 "차례" 표시를 단다.
   - 내 차례면 "(나)" 줄과 손패 칸이 빛나고, 휴대폰이 한 번 짧게 진동한다(효과음을 끄면 진동도 없다).
   - 움직임 줄이기 설정(`prefers-reduced-motion`)이면 맥박을 끈다.
2. **손패 2줄**
   - 8장까지는 한 줄이다. 9장부터는 반씩 두 줄이다(윗줄이 한 장 더 많다).
   - 줄이 폭을 넘으면 카드가 서로 겹친다. 각 카드를 감싸는 칸이 줄어들고, 마지막 카드는 다 보인다.
3. **랭킹 순서**
   - `GET /api/users/ranking/games` 는 게임별 판수다. `user_game_stats` 의 승+패 합이고 봇은 뺀다.
   - 판수가 많은 게임이 앞이고 처음 탭이 된다. 판수가 없는 게임은 카탈로그 순서로 뒤에 둔다.
