# 모바일 반응형 체크리스트 (M1/A3)

자동 테스트(jsdom)는 레이아웃을 계산하지 않으므로, 모바일 UX 는 아래 수동 체크로
검증한다. 브라우저 개발자도구의 디바이스 모드(또는 실기기)에서 대표 폭
**360 / 390 / 768px** 로 점검한다.

> 자동 가드: `useHandOverlap.test.ts`(손패 겹침 계산), `CardChip.test.tsx`(이미지/폴백).
> 터치 타겟: 보조 버튼은 `@media (pointer: coarse)` 로 ≥44px 보강(styles.css).

## 실행

```bash
npm --prefix client run dev   # 5173, /api·/ws → 8080 프록시
# 로그인 → 미르보드카페 → 방 만들기(봇 채움) → 게임판
```

## 체크 항목

### 메인(미르보드카페)
- [ ] 헤더(제목·아바타·게임방법·테마·로그아웃)가 360px 에서 줄바꿈되며 겹치지 않음
- [ ] 게임 카드 그리드 1열로 정렬, "자세히" 링크 탭 가능
- [ ] 방 목록/랭킹/로비채팅이 세로로 쌓이고 가로 스크롤 없음
- [ ] "게임 방법" 버튼 → 튜토리얼 모달이 화면 안에 들어오고 단계 이동 가능

### 대기실(Room)
- [ ] 참가자 목록·준비 버튼·팀 정책 셀렉터가 한 화면에 수용
- [ ] 준비/나가기 버튼 터치 타겟 충분(≥44px)

### 게임판(GameTable) — 핵심
- [ ] 4인 원형 좌석(S/W/N/E)이 360px 에서 겹치거나 화면 밖으로 넘치지 않음
- [ ] 중앙 트릭 영역이 좌석/손패와 겹치지 않음
- [ ] 손패: **탭 = 선택**, **드래그 = 재배열** 이 명확히 구분(8px 임계)
- [ ] 손패 14장이 한 줄에서 겹쳐 들어오고 가장자리 카드가 잘리지 않음
- [ ] 카드 이미지가 보이고(글리프 아님), 누락 시 글리프 폴백
- [ ] 액션 버튼(내기/패스/플레이/취소)·패스 슬롯 터치 타겟 ≥44px
- [ ] 특수 카드 모달(소원/용 양도)·패스 받기 모달이 화면 안에 수용

### 회전/리사이즈
- [ ] 세로↔가로 전환 시 손패 겹침이 재계산되어 넘치지 않음(ResizeObserver)
- [ ] 라이트/다크 토글이 모바일에서도 정상

## 알려진 한계
- jsdom 미커버 영역(실제 좌표/터치)은 본 체크리스트로만 검증.
- DnD 8px 임계는 스크롤 제스처와 미묘하게 경합할 수 있어 실기기 확인 권장.
