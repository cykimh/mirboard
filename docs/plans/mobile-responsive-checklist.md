# 모바일 반응형 체크리스트 (M1/A3)

자동 테스트(jsdom)는 레이아웃을 계산하지 않으므로, 모바일 UX 는 아래 수동 체크로
검증한다. 브라우저 개발자도구의 디바이스 모드(또는 실기기)에서 대표 폭
**360 / 390 / 768px** 로 점검한다.

> 자동 가드: `useHandOverlap.test.ts`(손패 겹침 계산), `CardChip.test.tsx`(이미지/폴백).
> 터치 타겟: 보조 버튼은 `@media (pointer: coarse)` 로 ≥44px 보강(styles.css).

## 실행

```bash
npm --prefix client run dev   # 5173, /api·/ws → 8080 프록시
# 로그인 → 미르보드카페 → 방 만들기(봇 채움) → 게임판
```

## 체크 항목

### 메인(미르보드카페)
- [ ] 헤더(제목·아바타·게임방법·테마·로그아웃)가 360px 에서 줄바꿈되며 겹치지 않음
- [ ] 게임 카드 그리드 1열로 정렬, "자세히" 링크 탭 가능
- [ ] 방 목록/랭킹/로비채팅이 세로로 쌓이고 가로 스크롤 없음
- [ ] "게임 방법" 버튼 → 튜토리얼 모달이 화면 안에 들어오고 단계 이동 가능

### 대기실(Room)
- [ ] 참가자 목록·준비 버튼·팀 정책 셀렉터가 한 화면에 수용
- [ ] 준비/나가기 버튼 터치 타겟 충분(≥44px)

### 게임판(GameTable) — 핵심
- [ ] 4인 원형 좌석(S/W/N/E)이 360px 에서 겹치거나 화면 밖으로 넘치지 않음
- [ ] 중앙 트릭 영역이 좌석/손패와 겹치지 않음
- [ ] 손패: **탭 = 선택**, **드래그 = 재배열** 이 명확히 구분(8px 임계)
- [ ] 손패 14장이 한 줄에서 겹쳐 들어오고 가장자리 카드가 잘리지 않음
- [ ] 카드 이미지가 보이고(글리프 아님), 누락 시 글리프 폴백
- [ ] 액션 버튼(내기/패스/플레이/취소)·패스 슬롯 터치 타겟 ≥44px
- [ ] 특수 카드 모달(소원/용 양도)·패스 받기 모달이 화면 안에 수용 (용 양도 모달은 컴팩트 max-w-xs)

### 게임판 UX 폴리시 (A6 / UX-1~4)
- [ ] 헤더: 딜링→선언→패스→플레이 단계 전환 시 컨트롤(스피커/애니/😀/채팅) 위치 불변(우측 고정)
- [ ] 헤더에 'STOMP'·'내 시트' 미노출, 연결 상태는 점(.conn-dot)로 표시
- [ ] 점수는 아레나 "우리/상대" 한 곳만(헤더 누적 A:B 중복 없음)
- [ ] 리액션 팔레트(😀)가 아레나 점수판을 덮지 않음(우측 개방)
- [ ] 좁은 폭에서 채팅 열기 → 바텀시트로 좌석/테이블을 가리지 않음
- [ ] 카드 패스: 손패 + 3슬롯이 과도한 여백/sprawl 없이 컴팩트, 미선택 시 손패 강조→선택 시 슬롯 강조
- [ ] 좌석 배지: 내 좌석은 '나'(계정명 숨김), 파트너/상대는 계정명을 팀색 배지(우리=초록/상대=빨강)로 표시(긴 닉네임 말줄임). 별도 닉네임 줄 없음
- [ ] 패스(좌)·내기(우) 버튼이 내 좌석 양옆으로 충분히 벌어져 좌석/서로와 겹치지 않음

### 게임판 UX 폴리시 2차 (A7 / 카드·버튼·좌석스택)
- [ ] 카드: 트럼프 핍 SVG 대신 직관적 숫자+슈트 문양(좌측 정렬). 확대(데스크톱 62 / @768 54 / @480 48px)
- [ ] 플레이 단계 겹침 시에도 각 카드의 좌측 숫자+문양이 왼쪽 슬라이버에서 읽힘
- [ ] 특수카드(개/용/봉황/마작)는 고유 일러스트(SVG)로 식별, 로드 실패 시 이모지 폴백
- [ ] 색약 모드에서 슈트 글리프가 이중으로 찍히지 않음(1개), 색약 시 글리프 윤곽 강조
- [ ] 좌석 손패 스택: 나(남)=표시 안 함(아래 실제 손패로 장수 파악), 파트너(상단)=아래 부채, 좌·우 상대=세로(±90°)를 아바타 옆(중앙 쪽)에 배치
- [ ] 좌/우 상대의 옆-배치 세로 스택이 좌석 라벨(닉네임/팀칩)·중앙 트릭과 겹치지 않고 좁은 폭에서 잘리지 않음
- [ ] 중앙 트릭 패널이 좁은 폭에서 내 아바타·좌/우 스택·파트너 부채와 겹치지 않음(보드 세로 확대 + 패널/센터카드 컴팩트)
- [ ] 패스(좌)·내기(우)가 내 좌석 카드스택과 겹치지 않음, 내기가 '지금 낼 수 있을 때만' 골드 링으로 강조
- [ ] 취소 버튼 없음 — 플레이 중 손패·버튼 밖(빈 펠트/영역) 클릭 시 카드 선택이 해제됨
- [ ] 터치 기기에서 내기/패스 버튼 ≥48px, 취소 ≥44px

### 방 만들기 모달 (옵션 가시성 · 판돈 토글)
- [ ] 목표점수/턴제한 옵션이 선택 시 채움(primary)으로 또렷이 구분(미선택은 outline), hover 시에도 선택색 유지
- [ ] 판돈은 on/off 토글(Switch). ON = 기본 판돈 100칩 + 봇 자동 비활성, OFF = 내기 없음

### 회전/리사이즈
- [ ] 세로↔가로 전환 시 손패 겹침이 재계산되어 넘치지 않음(ResizeObserver)
- [ ] 라이트/다크 토글이 모바일에서도 정상

## 알려진 한계
- jsdom 미커버 영역(실제 좌표/터치)은 본 체크리스트로만 검증.
- DnD 8px 임계는 스크롤 제스처와 미묘하게 경합할 수 있어 실기기 확인 권장.

### 검토 도구 메모

- 내장 브라우저의 **좌표 클릭은 신뢰할 수 없다**. 패널 실제 폭이 401px 인데
  `resize_window` 는 CSS 뷰포트만 바꿔서, 오버라이드 상태의 입력 좌표가 패널 밖으로
  나가 전부 `<html>` 에 떨어진다(Radix Dialog 는 이를 바깥 클릭으로 보고 닫는다).
  → 앱 구동은 `javascript_tool` 의 `element.click()` / native setter + `input` 이벤트로,
  검증은 DOM 실측으로 한다.
- 오버라이드 폭에서는 **스크린샷도 실제 패널 배율로 렌더**돼 육안 확인이 안 된다.
  육안은 네이티브 폭(401)만, 와이드는 DOM 실측으로.
