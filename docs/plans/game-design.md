# 네 게임 디자인 트랙 (D-185)

요트·오목·구름항로·씨앗포에 **게임마다 다른 분위기**의 그림·질감·**움직임 연출**을 넣는다. 관제 세션이 단계마다 검증·병합한다.

## 사용자 결정 (2026-11-11)

| 항목 | 결정 |
|---|---|
| 방향 | 게임마다 다른 분위기(공통 그림체 아님) |
| 범위 | 색·질감 + 판·말·캐릭터 그림 + 움직임 연출 |
| 진행 | 게임마다 시안 2~3개 → 사용자가 고름 → 구현 |
| 모델 | 시안·그림·스타일 작업은 Fable 5.2, 검증·병합·게임 로직은 관제(Opus 5.5) |

## 원칙

- **연출은 화면만** — 서버 판정·차례·타이머·재생 길이(씨앗포 `replayLengthMs`)를 바꾸지 않는다. 연출 때문에 조작이 늦어지면 안 된다.
- **바꿔 끼우기** — 기본 모습은 남기고 게임별 테마 층으로 얹는다(씨앗포는 스킨 층 D-227 의 `ACTIVE_SKIN`). 되돌리기는 한 줄.
- **게임 CSS 네임스페이스·part 유지** — 요트 `.yt-` 20, 오목 `.om-` 21, 구름항로 `.cr-` 22, 씨앗포 `.ar-` 23. 공용 클래스 재정의 금지.
- **확인 기준** — 라이트·다크, 휴대폰 375px, `prefers-reduced-motion`(연출 끔), 글자 대비, 그림 용량(게임당 수백 KB 안), 60fps.
- **독창** — 다른 게임·작품의 그림·캐릭터를 베끼지 않는다(포트리스 등 포함).
- **코드로 만드는 그림 우선** — SVG·CSS·Canvas·생성 스크립트. 손그림 래스터가 필요하면 형식만 정해 두고 사람이 넣는다.

## 단계

| 단계 | 내용 | 산출물 | 상태 |
|---|---|---|---|
| D1 시안 | 게임마다 분위기가 다른 시안 2~3개 — 실제 판 상태 한 장면(데스크톱·375px), 움직임 연출 데모 포함 | 독립 HTML 시안 + 한 줄 설명, 비교 페이지 | 진행 |
| D2 선택 | 사용자가 게임마다 하나 고름(섞기 가능) | 결정 기록(게임 블록) | |
| D3 구현 | 고른 시안을 테마 층으로 — 그림·질감·연출 | 게임별 브랜치 → 관제 PR | |
| D4 확인 | 로컬 실제 봇 판(데스크톱·375px·라이트/다크·연출 끔) 스크린샷 대조 → PR CI → main | | |

### 게임별 진행

| 게임 | D2 선택 | D3 구현 | D4 확인 |
|---|---|---|---|
