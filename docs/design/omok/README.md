# 오목 게임판 시안 (D-185 · D1)

오목 게임판의 **분위기만** 바꾼 시안 3개. 구성 요소(판·좌표, 돌, 마지막 수, 금수 ✕, 두 단계 확정 착수, 차례 띠, 5목 줄, 결과 카드)와
클래스 이름(`.om-*`)은 지금 앱과 같다. 앱 코드는 건드리지 않았다.

| 파일 | 이름 | 한 줄 |
|---|---|---|
| [`option-a.html`](option-a.html) | **결** | 등불 아래 나무 바둑판, 조개 백돌과 흑석 — 돌이 "딱" 내려앉는 무게감 |
| [`option-b.html`](option-b.html) | **먹** | 한지에 붓으로 그은 판, 먹 번짐으로 놓이는 돌, 주홍 낙관 |
| [`option-c.html`](option-c.html) | **별자리** | 밤하늘 격자에 별을 놓는다 — 5목이면 별자리가 이어진다 |

## 보는 법

- 파일을 브라우저로 그냥 연다(외부 의존 없음 — 글꼴도 시스템 글꼴).
- 넓은 화면: 왼쪽 **데스크톱(게임판 최대 640px)**, 오른쪽 **휴대폰 375px** 틀. 좁은 화면(820px 이하)에서는 게임판 하나만 화면 폭에 맞춰 보인다.
- 장면: 2:2 팀전·렌주, 30수 진행(흑이 넷을 만든 중반), 마지막 수 E5(백), 흑 금수 2곳(M6·E3 삼삼), 내 차례(흑).
- 판을 누르면 미리보기 → **같은 자리를 한 번 더** 누르거나 [여기에 두기]로 확정. 끌면 미리보기가 따라온다. 키보드는 화살표 + Enter.
  시안에서는 네 자리 모두 대신 둘 수 있다(차례 넘김 연출 확인용).
- 위쪽 버튼: **5목 연출 보기**(J10 에 두어 끝냄) · **금수 경고 보기** · **네 수 자동 진행** · 처음 장면으로 · 라이트/다크 · 연출 줄이기.
- 처음 열 때 OS 의 다크 모드·`prefers-reduced-motion` 을 따른다. 연출 줄이기에서는 모든 애니메이션이 끝 상태로 바로 간다(줄·표식은 남고 움직임만 없다).
- 룰 판정은 흉내다 — 5목 검사만 진짜고 금수 자리는 미리 정해 둔 두 점이다.

## A · 결

- **콘셉트**: 고전 대국실. 짙은 나무 틀 안에 결이 흐르는 판, 흑석(무광 슬레이트)과 조개 백돌(조개 줄무늬가 돌마다 다른 각도). 다크는 방이 어두워지고 등불 비네트만 짙어진다 — 판은 두 테마 모두 밝은 나무(지금 앱과 같은 원칙).
- **팔레트**: 판 `#ecc582→#d9a85c`, 틀 `#8a5a2b→#5e3a18`, 줄 `#3f2a12`, 놋쇠 `#b8862f`/`#dba844`, 금 상감 `#f7d36a`, 금수 주홍 `#b3261e`. 바탕 라이트 `#f2e9d8` / 다크 `#1c150e`.
- **타이포**: 제목·좌표는 명조 계열(시스템), 나머지는 고딕.
- **연출**
  - 돌 놓기: 위에서 내려와 살짝 눌렸다 자리 잡음(0.36s) + 그림자가 모임 + 나뭇결 파문 두 겹 + 틀이 1.5px 눌림
  - 미리보기: 떠 있는 반투명 돌 + 천천히 도는 점선 고리, 놋쇠 점선 안내선
  - 금수 경고: ✕ 가 커지며 고개를 젓고, 붉은 고리가 퍼지고, 틀이 좌우로 한 번 흔들림
  - 마지막 수: 금빛(흑 위)·주홍(백 위) 점 + 한 번 퍼지는 고리
  - 5목: 금 상감 줄이 그어지고(0.7s) 돌이 차례로 들썩이며 네 갈래 반짝임 → 놋쇠 테 현판 결과 카드
  - 차례 넘김: 놋쇠 고리가 다음 명패로 튕기듯 미끄러지고, 그 자리 돌 아이콘이 통 튄다. 내 차례면 틀에 놋쇠 빛이 숨 쉰다
- **구현 난이도**: 낮음~중간. 돌 = 그라데이션 3개 + 경로 1개, 나뭇결 = `feTurbulence` 필터 1개(정적, 한 번만 그림).
- **예상 용량**: CSS 약 7KB + SVG defs·조각 약 3KB(압축 전). 이미지 0.

## B · 먹

- **콘셉트**: 수묵화 한 장을 같이 그린다. 줄은 손으로 그은 듯 굵기·떨림이 조금씩 다르고, 흑돌은 먹 얼룩(농담 한 겹), 백돌은 붓으로 두른 동그라미. 색은 먹과 주홍 둘뿐. 다크는 "밤 한지" — 먹지 위에 흰 줄, 흑돌에 옅은 테.
- **팔레트**: 한지 `#f5efe0` / 밤 한지 `#2b2925`, 먹 `#1c1a18` / 흰 먹 `#d2c9b7`, 주홍 `#c8372d` / `#e2604f`, 담채 `#5f6f76`.
- **타이포**: 전부 명조 계열(시스템), 자간 넓게. 배지는 각진 테.
- **연출**
  - 돌 놓기: 붓끝이 닿아 먹이 스미듯 커짐(0.5s) + 번짐이 두 배로 퍼지며 사라짐 + 먹 방울 일곱 개가 튐(백돌은 담채 색)
  - 미리보기: 옅은 먹 돌이 숨 쉬고, 한 붓에 그려지는 원(끝이 열린 일원상), 젖은 붓 같은 넓고 옅은 안내선
  - 금수 경고: 주홍 붓 ✕ 가 도장처럼 눌러 찍히고 붉은 물이 번짐, 족자가 살짝 기울었다 돌아옴
  - 마지막 수: 작은 주홍 낙관이 찍힘
  - 5목: 주홍 큰 붓이 다섯 돌을 한 획에 긋고 마른 붓 자국 두 줄이 따라옴, 돌에 먹이 다시 번짐 → 종이 띠가 가운데서 펼쳐지고 "승" 낙관이 쾅
  - 차례 넘김: 붓 밑줄이 다음 이름 아래로 다시 그어진다. 내 차례면 족자 바깥 테가 주홍으로 숨 쉰다
- **구현 난이도**: 중간. 돌·줄 모양을 씨앗값으로 만드는 작은 함수(`blob`, 약 10줄)가 필요 — 필터를 쓰지 않아 돌이 많아져도 가볍다. 한지 결은 정적 필터 2개.
- **예상 용량**: CSS 약 7KB + SVG·TS 약 4KB(압축 전). 이미지 0(산 능선은 CSS 안 인라인 SVG 400B).

## C · 별자리

- **콘셉트**: 판이 하늘이다. 줄은 옅고 교차점마다 작은 별빛, 화점은 네 갈래 별. 흑 = 신월(어두운 구에 초승달 빛 테), 백 = 보름별(빛무리). 다크가 본모습(밤하늘), 라이트는 새벽 하늘(연보라→살구).
- **팔레트**: 밤 `#0b1030→#17123f→#0a1a3a`, 성운 `#5a3fd0`·`#0f7fa8`, 빛 `#7de3ff`, 금 `#ffd27d`, 금수 `#ff6b81`. 새벽 `#cfd6ff→#ecd9f3→#ffe6cf`, 강조 `#3a4fd0`, 금 `#c27a00`.
- **타이포**: 고딕 + 넓은 자간, 좌표·시계는 고정폭.
- **연출**
  - 돌 놓기: 빛점에서 부풀어 오름(0.5s) + 네 갈래 섬광이 돌며 사라짐 + 별가루 여섯 + 하늘에 번지는 파문 두 겹
  - 미리보기: 조준 고리(도는 점선 + 눈금 넷)가 조여들고, 안내선은 흐르는 광선
  - 금수 경고: 평소엔 붉은 고리 ✕ 가 천천히 깜박, 누르면 붉은 파문 두 겹 + 지직 흔들림
  - 마지막 수: 돌 둘레를 도는 작은 금빛 위성
  - 5목: 별에서 별로 금빛 선이 한 마디씩 이어지고(0.24s × 4) 별마다 섬광, 끝에 별똥별이 판을 가로지름 → 유리 카드 "별자리 완성"
  - 차례 넘김: 빛나는 테가 다음 자리로 미끄러지고 띠 위로 빛이 한 번 쓸고 감. 내 차례면 판 테두리에 빛무리가 숨 쉰다. 배경 별 몇 개는 늘 반짝임
- **구현 난이도**: 중간. 요소 수가 가장 많다(교차점 별 225 + 배경 별 80) — 정적이라 부담은 작지만 늘 도는 애니메이션(반짝임·위성·조준 고리)이 있어 저사양 기기 확인이 필요.
- **예상 용량**: CSS 약 9KB + SVG·TS 약 5KB(압축 전). 이미지 0.

## 구현으로 옮길 때 (D3 참고)

- 테마 층: `.om-tokens` 에 테마 클래스 하나(예: `.om-theme-ink`)를 얹고 색 토큰·돌 그림만 바꾼다. 클래스를 떼면 지금 모습.
- 건드릴 파일 예상: `client/src/styles/parts/21-omok-table.css`(토큰·연출 keyframes, 폭 미디어 0개 유지), `client/src/features/omok/OmokBoard.tsx`
  (SVG `<defs>`, 돌을 `<circle>` → 테마별 조각, 놓기·금수·5목 효과 층), `OmokTable.tsx`(차례 표식, 판 틀·좌표 눈금), `OmokMatchEnd.tsx`(결과 카드 장식),
  튜토리얼 미니 판(`tutorial/`)도 같은 돌을 쓰면 함께.
- 시안의 좌표 눈금(A~O·15~1)은 판 폭 480px 이상에서만 보인다 — 375px 에서는 칸을 줄이지 않으려고 숨기고 상태 줄의 좌표 이름(K10)으로 대신한다.
- 375px 에서 칸 크기는 22.4~23.5px(지금 앱과 같은 수준). 두 단계 확정·끌기는 그대로 둔다.
- 연출은 화면만 — 놓은 돌은 바로 판에 있고(연출이 입력을 막지 않음), 결과 카드만 5목 줄이 다 그어진 뒤(1.5~2.1s) 뜬다. 연출 줄이기에서는 바로 뜬다.

## 확인한 것

- 브라우저(Chromium)에서 세 파일 모두: 라이트·다크, 1280px·375px, 가로 스크롤 없음, 콘솔 오류 없음, 5목·금수·자동 진행 동작.
- 확인 못 한 것: Safari·Firefox 실기기, 저사양 휴대폰 프레임률.

세 파일의 뼈대 CSS(`.mk-*`·`.om-*` 구조)와 맨 아래 데모 스크립트는 같은 내용이다. 그림·색·연출은 파일마다 `시안 X` 주석 아래 CSS 와 `window.OM_THEME` 에 있다.

## 2차 — 연출 고도화 (D-194)

판·주변 칸·배치는 D-192·D-193 그대로이고 연출만 얹었다. 되돌리기는 `client/src/features/omok/omokTheme.ts` 의
`OMOK_FX = 'basic'` 한 줄(클래스 `om-fx-rich` 가 빠져 D-193 모습 그대로). 새 그림 파일은 없다 — 전부 인라인 SVG 도형 + CSS
(`21-omok-table.css` 맨 끝 "D-194" 구획, 미디어 0개 — 움직임 줄이기는 17 의 기존 `.om-tokens *` 블록이 끈다).

| 장면 | 연출 | 길이 |
|---|---|---|
| 착수 | 얕은 잔물결 세 겹(겹마다 더 멀리·더 가늘게) + 등불 받는 쪽 밝은 호 | 닿은 뒤 약 1.3초 |
| 마지막 수 | 점 + 번짐 두 번 → 가는 고리 하나로 멈춤(상시 깜빡임 없음) | 약 3초 뒤 정지 |
| 5목 | 0.14초 박자로 불티가 돌에서 돌로 — 구간 빛줄기·돌 들썩임·고리 번짐·오르는 음 → 줄 전체 빛 한 번 → 이긴 돌에 가는 금 고리가 남음 | 약 1.2초 |
| 종료 배너 | 판 위(승리 줄 반대쪽 절반) "흑 5목!" + 이름 — 이긴 쪽·진 쪽·관전자 같은 크기. 기권·시간 초과·나감은 작은 무채색 띠 "백 승 · ○○ 기권", 무승부는 "무승부" | 2.6초 / 2.2초 |
| 현판 | 5목이 아니면 빛이 쓸고 가지 않음, 진 색 돌은 흐리게, 무승부는 테가 무채색 | — |
| 강하게 두기 | 낙하 잔상 → 닿는 순간 판 전체 주홍 번쩍임·방사 빛살 10줄·먼 충격파 한 겹 추가, 돌가루 셋 중 하나는 불티색, 잔물결도 닿는 때에 맞춤. 배너는 도장처럼 찍히고 빛이 한 번 쓸고 1.6초 안에 사라짐 | 약 1.3초 |

넣지 않은 것: 위협 표시(열린 3·4 강조) — 룰 도움말이 된다. 판 바탕·상시 장식 변화 없음.

실제 판 확인(게스트 + 봇, 로컬): 데스크톱 라이트·다크, 375×812 라이트·다크. 스크린샷 `shots/d194-*.jpg`(연출을 멈춰 찍음).
