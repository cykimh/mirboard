# 스컬킹 — "촛불 선장실" (D-231, 디자인 2차 D-187)

낡은 나무 갑판·양피지·놋쇠·흔들리는 촛불 빛. 모험 그림책처럼 따뜻하고 약간 어둑하게.

- **테마 층**: `client/src/features/skullking/skullKingTheme.ts` 의 `SKULL_KING_THEME`. `'classic'` 으로 바꾸면 예전 모습 그대로다
  (그림·연출 조각은 테마일 때만 그려지고, 꾸밈 CSS 는 전부 `.sk-theme-cabin` 아래).
- **카드**: `SkullCardArt.tsx` — 무늬 넷(닻·등불·금화·검은 깃발)과 특수 다섯(해적·인어·스컬킹·티그리스·탈출). 무늬 카드는 왼쪽 위
  숫자 + 오른쪽 아래 상징, 특수 카드는 종류별 색 양피지 + 그림 + 이름 + 왼쪽 위 봉랍 한 글자(겹친 손패에서 읽힌다).
- **연출**(화면 전용, `prefers-reduced-motion` 이면 끔): 카드 내기 비행·착지(낸 사람 쪽에서), 예측 공개 양피지 + 좌석 숫자 뒤집힘,
  트릭 승자(다른 카드가 승자 쪽으로 끌림 + 놋쇠 빛, 좌석 번쩍), 포획 보너스 "+30/+20/+40" 튀어 오름, 라운드 정산 금화/물방울,
  매치 종료 보물 상자 + 금화 비, 차례 촛불 맥박.
- **만들지 않은 것**: 크라켄·흰고래 연출 — 이 구현의 룰(`docs/rules-skullking.md`)에 그 카드가 없다(특수 5종).
- 그림 출처는 `CREDITS.md`, 실제 판 화면은 `shots/`.
