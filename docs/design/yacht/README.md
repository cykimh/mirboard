# 요트 게임판 디자인 시안 (D-185 · D1)

`docs/plans/game-design.md` 의 D1 단계 산출물. 시안 3개는 **화면 구성은 지금 게임판 그대로**(좌석 띠 · 주사위 판 · 굴리기/고정 ·
후보 점수가 뜨는 점수표 · 차례 카운트다운 · 결과 화면)이고 분위기와 움직임만 다르다. 앱 코드는 건드리지 않았다.

| 파일 | 이름 | 한 줄 콘셉트 |
| --- | --- | --- |
| [`option-a.html`](option-a.html) | **A · 미드나잇 살롱** | 늦은 밤 살롱의 초록 펠트와 황동 — 상아 주사위가 옆에서 던져져 구르고, 점수는 황동 칩이 장부에 꽂히며 적힌다 |
| [`option-b.html`](option-b.html) | **B · 공방 나무 트레이** | 보드게임 카페의 나무 트레이와 손글씨 점수지 — 나무 주사위가 위에서 떨어져 통통 튀고, 점수는 색연필 동그라미로 적힌다 |
| [`option-c.html`](option-c.html) | **C · 항구 깃발** | 맑은 항구의 스티커 그림책 — 주사위가 물 위에 떠 있다가 물보라를 내며 뛰고, 요트가 나오면 만국기와 돛단배가 지나간다 |

## 보는 법

- 세 파일 모두 **외부 의존 없는 단독 HTML**(인라인 CSS · SVG · JS, 이미지 · 웹폰트 · 라이브러리 0). 브라우저로 바로 연다.
- 같은 장면(4인 · 내 차례 · 굴림 2/3 · 4 세 개 고정 · 점수표 5칸씩 채움)을 **데스크톱 폭(최대 760px)** 과 **375px** 로 나란히 보여 준다.
  좁은 화면에서는 두 판이 위아래로 쌓이고 가로 스크롤이 없다.
- 위쪽 버튼: **[굴려 보기]**(고정 유지) · **[5개 모두 굴리기]** · **[요트 내 보기]** · **[점수 기록해 보기]** · **[결과 화면]** · **[처음으로]**,
  **[라이트 / 다크]**, **[연출 줄이기]**. 판 안의 주사위(고정) · [굴리기] · 점수표 후보 칸(기록)도 직접 눌린다.
- 처음 테마는 `prefers-color-scheme`, 처음 연출 세기는 `prefers-reduced-motion` 을 따른다. 연출을 줄이면 눈 · 점수만 바로 바뀌고
  축하는 상태 줄 배지 한 개로만 알린다.
- 굴림 연출 길이는 세 시안 모두 **600ms**(앱 `ROLL_ANIMATION_MS` 와 같음, 주사위마다 40~50ms 엇갈림)다. 연출은 조작을 막지 않는다
  (축하 층은 `pointer-events: none`).

## 시안별 정리

### A · 미드나잇 살롱

- **분위기**: 어둡고 차분한 고급 탁자. 명조 계열 글자, 넓은 자간, 금색 가는 선.
- **팔레트**

  | 쓰임 | 다크 | 라이트 |
  | --- | --- | --- |
  | 배경 | `#0b110e` | `#efe9dc` |
  | 펠트 | `#17503a` (밝은 곳 `#23704f`) | `#2f7d5b` (밝은 곳 `#44a077`) |
  | 레일(나무) | `#3a2417` | `#6b4226` |
  | 황동 | `#d6b25e` / `#f6e2a4` | `#a8842f` / `#e9d08a` |
  | 주사위 | 상아 `#fffaf0`→`#d9caa6`, 눈 검정, 1 눈만 와인 `#a8243c` | 같음 |
  | 장부(점수표) | `#0f1915` + 금선 | `#fffbf2` + 금선 |

- **주사위 · 점수표**: 상아 그라데이션 SVG 주사위(1 눈은 큰 와인색). 점수표는 금선 장부 — 후보 점수는 황동 테두리 알약, 총점 줄은 겹줄.
- **연출**
  - 굴림: 오른쪽 레일 너머에서 **던져져 굴러와**(회전 620°) 왼쪽으로 살짝 지나쳤다가 한 번 튀고 멈춤. 구르는 동안 눈이 바뀜.
  - 고정: 주사위가 눌려 내려앉고 황동 테 + **"고정" 황동 명패**가 펼쳐짐.
  - 점수 기록: **황동 칩**이 주사위 자리에서 칸으로 날아가 꽂힘 → 칸에 금박이 훑고 숫자가 눌려 찍힘, 좌석 총점이 올라감.
  - 요트: 펠트 위로 **금빛이 한 번 훑고**, 주사위가 차례로 빛나며 뜀, 금가루 28개, 가운데 "요트" 띠.
  - 내 차례: 레일의 황동 선이 천천히 밝아졌다 어두워짐. 결과 카드는 아래에서 떠오름.
- **구현 난이도**: **CSS + 인라인 SVG**(주사위 6면 · 칩 · 좌석 칩 아이콘). 펠트 질감은 CSS 안의 SVG 노이즈 한 장. Canvas 불필요.
- **예상 용량**: CSS 약 8KB + SVG · 연출 코드 약 4KB (시안 파일 36KB 중 판 뼈대 · 데모 코드가 21KB).

### B · 공방 나무 트레이

- **분위기**: 따뜻하고 손맛 나는 카페 탁자. 본문은 기본 고딕, **점수 숫자만 손글씨체**. 다크는 칠판 + 분필.
- **팔레트**

  | 쓰임 | 라이트 | 다크 |
  | --- | --- | --- |
  | 배경 | `#efe3cf` | `#17110c` |
  | 나무 | `#c08a52` / `#8f5f33` | `#6e4526` / `#3f2715` |
  | 트레이 안감(쪽빛 가죽) | `#31506a` | `#1f3a4d` |
  | 주사위 | 단풍나무 `#f6ddb0`→`#cfa56a`, 눈은 태운 갈색 `#3a2212` | 같음 |
  | 점수지 | 종이 `#fdf8ec`, 줄 `rgba(60,110,160,.24)`, 색연필 `#c0392b` | 칠판 `#202c28`, 분필 `#ece8da`, 호박색 `#f0b35a` |
  | 버튼 | 테라코타 `#b5632b` + 흰 스티치 | 같음 |

- **주사위 · 점수표**: 나뭇결 선이 있는 나무 주사위. 쉬는 주사위는 **조금씩 삐뚤게** 놓이고, 고정하면 반듯해진다.
  점수표는 마스킹 테이프로 붙인 줄 공책(왼쪽 빨간 여백선) — 후보는 연필 점선 상자.
- **연출**
  - 굴림: **위에서 떨어져** 바닥에 닿는 순간 눈이 정해지고, 두 번 통통 튄 뒤 제 각도로 멈춤. 닿을 때 트레이가 살짝 눌림.
  - 고정: 주사위가 반듯하게 돌아오며 **아래 홈에 꽂힘**(주사위마다 파인 홈이 늘 보인다).
  - 점수 기록: 숫자가 한 획씩 써지고 **색연필 동그라미**가 그려짐(동그라미는 다음 기록까지 남는다), 좌석 총점이 올라감.
  - 요트: **"요트! 50점" 도장**이 쾅 찍히고 트레이가 흔들림, 주사위가 차례로 폴짝, 색종이 30장이 팔랑팔랑.
  - 내 차례: 트레이 바깥에 좌석 색 테두리가 숨 쉬듯. 결과 카드는 종이가 위에서 내려앉음.
- **구현 난이도**: **CSS + 인라인 SVG**(주사위 · 동그라미 · 도장 · 말 아이콘). 나뭇결은 CSS 안의 SVG 노이즈. Canvas 불필요.
  손글씨체는 기기 글꼴에 기대므로(없으면 기본 필기체로 대체) **글꼴 결정이 따로 필요**하다 — 아래 "위험".
- **예상 용량**: CSS 약 8KB + SVG · 연출 코드 약 5KB. 숫자 전용 웹폰트를 넣으면 +10~20KB(숫자 · 기호만 추린 woff2).

### C · 항구 깃발

- **분위기**: 밝고 장난스러운 스티커 그림. 굵은 외곽선 + 딱 떨어지는 그림자, 굵은 고딕. 게임 이름(요트)에서 가져온 항구 소재.
- **팔레트**

  | 쓰임 | 라이트 | 다크(밤 항구) |
  | --- | --- | --- |
  | 배경 | `#e3f4fb` | `#070f24` |
  | 하늘 / 바다 | `#c4ebf9` / `#55bfe8`→`#1f86c9` | `#1a2a57` / `#2259ad`→`#0d2c68` |
  | 외곽선 · 글자 | 남색 `#12305a` | 외곽선 `#03081a`, 글자 `#eaf2ff` |
  | 강조 | 산호 `#ff5a4d`, 해 `#ffc93c`, 민트 `#22b99a` | `#ff6b5e`, `#ffd257`, `#35d0b0` |
  | 주사위 | 흰색 + 남색 외곽선 · 눈, 1 눈만 산호 | 같음 |

- **주사위 · 점수표**: 굵은 외곽선 스티커 주사위가 **수면에 떠서 까딱**거린다. 점수표는 둥근 색 블록 칸 — 후보는 노란 버튼, 총점 줄은 남색(다크는 노랑) 띠.
- **연출**
  - 굴림: 눌렸다가 **물 위로 뛰어올라 한 바퀴** 돌고 납작하게 내려앉음(찌그러짐 · 늘어남), 내려앉을 때 **물결 고리 + 물방울 3개**.
  - 고정: **닻을 내림** — 까딱임이 멈추고 가라앉으며 닻 아이콘 "고정" 표, 작은 물결.
  - 점수 기록: **삼각 깃발**이 칸으로 날아가 꽂히고 칸이 통 튀며 색이 바뀜, 좌석 총점 위로 "+N" 이 떠오름.
  - 요트: **만국기**가 위에서 차례로 펼쳐지고 **돛단배**가 수평선을 지나감, 주사위 파도타기 2번, "요트! +50" 스티커.
  - 늘 움직임: 파도 3겹이 흐름(연출 줄이기면 멈춤). 내 차례는 노란 테두리가 숨 쉬듯.
- **구현 난이도**: **CSS + 인라인 SVG**(주사위 · 파도 · 깃발 · 닻 · 돛단배 · 만국기). 세 시안 중 SVG 조각이 가장 많고 늘 도는 애니메이션이 있다. Canvas 불필요.
- **예상 용량**: CSS 약 9KB + SVG · 연출 코드 약 6KB.

## 위험 · 확인할 것

- **축하 시점**: 지금 앱은 큰 칸을 *기록할 때*만 축하한다. 시안은 5개가 같게 *멈춘 순간*에도 축하한다(주사위 값만 보고 화면에서 판단 — 서버 변경 없음).
  기록 때만으로 줄일 수도 있다.
- **굴림 길이**: 600ms 안에 맞췄지만 주사위마다 엇갈림(최대 +200ms)이 붙는다. 봇 템포(700ms)에서 연속 굴림이 겹치면 엇갈림을 줄여야 한다.
- **B 손글씨체**: 기기마다 글꼴이 달라 숫자 모양이 흔들린다. 숫자만 추린 글꼴을 넣거나 숫자를 SVG 로 그릴지 정해야 한다.
- **C 늘 도는 움직임**: 파도 · 까딱임이 계속 돈다(`transform` 만 써서 가볍다). 저사양 휴대폰에서 실제 판으로 60fps 확인 필요.
- **A · B 질감**: SVG 노이즈 필터 배경은 브라우저가 한 번 그려 캐시하지만, 아주 큰 화면에서 처음 그릴 때 비용이 있다. 문제가 되면 작은 PNG 로 바꾼다.
- **글자 대비**: 후보 점수(흐린 숫자)와 0점 칸은 일부러 옅다 — 구현 때 WCAG AA 로 다시 잰다(특히 A 라이트의 황동 글자, C 의 55% 불투명 후보).
- **색만으로 구분하지 않기**: 고정은 세 시안 모두 위치(내려앉음) + "고정" 글자표가 함께 있다. 좌석 색은 이름과 함께 쓴다.
- 시안의 점수 계산 · 장면 데이터는 데모용이다(실제 후보 점수는 서버가 준다).

## 구현 결과 — 시안 A "미드나잇 살롱" (D-203)

사용자가 A 를 골라 앱에 넣었다(`design/yacht-salon`). 시안에서 더 나아간 점:

- **굴림**: 평면 회전 대신 **여섯 면 정육면체**(CSS 3D)가 던져져 굴러와 바닥 그림자와 함께 한 번 튀고 멈춘다. 600ms 안(40ms 엇갈림 × 4 + 440ms).
- **기록**: 황동 칩이 잔상을 끌고 날아가 꽂히며 칸에 고리·금박·불티. 동시 진행에서는 그 사람 좌석 명패에서 출발한다.
- **요트 축하**(요트 칸에 기록할 때): 빛줄기 + 섬광 + 금박 현수막(누가·몇 점) + Canvas 금가루 폭발 3발 + 펠트 흔들림. 5개가 같게 멈춘 순간은 주사위 반짝임만.
- **차례 조명**: 펠트 위 등불이 차례인 좌석 쪽으로 옮겨 간다. "차례" 는 명패 모서리 리본(좌석 띠 높이가 바뀌지 않는다).
- **장부**: 줄 높이를 고정해 후보 칸이 떠도 표가 출렁이지 않는다. 위쪽 6칸 이름 옆에 작은 주사위. 내 열은 옅은 황동 물.
- **대비**: 후보 점수를 흐리게 하지 않고 황동 잉크색으로(AA). 펠트 위 글자는 어두운 받침 위에만.
- 결과 카드는 뜰 때 화면 안으로 올라오고, 내가 1위·새 최고 기록이면 금가루가 터진다.
