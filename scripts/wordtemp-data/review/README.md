# 낱말 온도 표 검수 — 이렇게 보면 돼요

표의 온도가 사람 감각과 맞는지 보는 표본입니다. 기준은 **띠 일치 80% 이상**(설계서 §5.2).

## 1. `review-sample.csv` (150쌍 — 띠별로 골고루, 무작위)

엑셀·넘버스·구글 시트로 열면 됩니다(한글이 깨지지 않게 저장돼 있어요).

| 칸 | 뜻 |
| --- | --- |
| 정답 · 뜻풀이 | 숨기는 낱말과 그 뜻 |
| 힌트 · 온도 · 띠 | 출제자가 낸 낱말, 표가 매긴 온도와 띠 |
| **판정(O/X)** | 이 띠가 맞다고 느끼면 `O`, 아니면 `X` |
| 내가 보는 띠 | `X` 일 때만: `A` 거의 정답(96+) · `B` 뜨거움(75~95) · `C` 미지근(40~74) · `D` 차가움(40 미만) |
| 메모 | 하고 싶은 말 |

띠의 감각:

- **거의 정답(96+)** — 사실상 같은 말. 이 힌트만 듣고도 대부분 정답을 말한다. (힌트 단계가 그 자리에서 끝나는 값)
- **뜨거움(75~95)** — 정답을 설명할 때 가장 먼저 나오는 낱말(핵심 특징·부분·바로 위 갈래).
- **미지근(40~74)** — 느슨하게 이어진다(같은 넓은 갈래, 같이 쓰는 물건·장소·상황).
- **차가움(40 미만)** — 거의 상관없다.

숫자가 조금 다른 것은 괜찮고 **띠가 맞는지**만 봅니다. 다 적은 뒤:

```bash
node scripts/wordtemp-data/07-review-sample.mjs --grade
```

일치율과 어긋난 쌍이 나옵니다. 친구와 같이 볼 때는 파일을 복사해 각자 적으면 됩니다.

## 2. `near-answer.csv` (96 이상 전부)

96 이상은 민감해서 전부 실었습니다. 한 줄씩:

- 정말 **같은 말**이면 `O` — 은행의 "같은 말" 목록으로 올릴 후보입니다(그러면 그 말은 추리 답으로 정답 처리되고, 힌트로는 못 냅니다).
- 같은 말이 아닌데 점수가 너무 높으면 `X` — 다음 표에서 고칩니다(예: 체온계 ↔ 온도계, 이발소 ↔ 이발사).

## 3. 정답 은행도 한 번 훑어 주세요

`server/src/main/resources/wordtemp/bank.tsv` — 낱말 · 범주 · 뜻풀이 · 같은 말.

- 빼고 싶은 낱말 → `scripts/wordtemp-data/data/bank-exclude.txt` 에 한 줄.
- 잘못된 같은 말 → `scripts/wordtemp-data/data/bank-alias-exclude.txt` 에 `낱말 같은말` 한 줄.
- 그 뒤 `node 01-bank.mjs && node 06-build.mjs && node validate.mjs` (Claude 를 다시 부르지 않습니다. 낱말을 빼기만 할 때).
